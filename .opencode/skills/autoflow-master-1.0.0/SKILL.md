# AutoFlow Master - 多场景自动化工作流生成与执行

## 快速开始

### 1. 描述需求

用自然语言描述你想自动化的任务，例如：
- "每天早上8点自动同步昨日Shopify订单到Excel"
- "当飞书收到客户订单消息时，自动同步到库存表，若库存不足则发送提醒"
- "检测B站视频发布后2小时播放量，若<500则转发到社群"
- "每周一自动整理上周邮件附件到指定文件夹"

### 2. 自动生成流程

Skill会自动拆解流程节点，例如：
```
【抓取Shopify订单数据】→【统计订单量/退货量】→【生成Excel日报】→【判断退货率】→【发送飞书通知】
```

### 3. 配置工具连接

选择需要联动的工具：
- 办公工具：飞书、钉钉、企业微信、Excel、Notion、Trello
- 电商工具：Shopify、Amazon、短信平台
- 本地工具：文件夹、浏览器、截图工具

### 4. 设置触发方式

- 定时触发：每天8点、每周一早上9点等
- 事件触发：收到消息、新增数据、文件上传
- 手动触发：点击"立即执行"按钮

### 5. 测试与部署

- 测试执行：验证流程是否通顺
- 查看日志：每次执行的详细记录
- 效率报告：每月自动生成节省时长统计

## 可用命令

### 创建工作流

```
创建工作流：[需求描述]
```

示例：
- `创建工作流：每天早上8点同步昨日订单到Excel`
- `创建工作流：客户下单自动发送确认短信`

### 查看与管理

```
查看工作流          - 列出所有已创建的工作流
查看工作流 [名称]   - 查看特定工作流的详情和执行日志
删除工作流 [名称]   - 删除指定工作流
```

### 手动执行

```
执行工作流 [名称]  - 立即执行指定工作流
```

## 预置模板

### 电商运营
- Shopify订单日报：每日自动统计订单量、销售额，生成报表发送到飞书
- 库存监控：实时监控库存量，低于阈值自动提醒采购
- 客户通知：下单确认、发货通知、退货处理自动短信/飞书通知

### 自媒体运营
- 视频数据监控：定时检测B站/抖音视频播放量，异常时触发推广
- 内容定时发布：支持多平台定时发布视频/图文
- 评论自动回复：检测新评论，自动回复或提醒运营人员

### 职场办公
- 邮件附件整理：每日自动将邮件附件归档到指定文件夹
- 日程同步：同步日历事件到飞书/钉钉
- 会议纪要：自动生成会议纪要并分发参会人

## 技术实现

### 工作流引擎

1. 解析自然语言需求
2. 拆解为可执行节点
3. 串联工具API
4. 设置触发条件
5. 执行并记录日志

### 支持的工具

- 消息：飞书、钉钉、企业微信、短信
- 数据：Excel、CSV、飞书表格、Notion
- 文件：本地文件夹、网盘
- 浏览器：自动化操作、数据抓取

### 执行模式

- 单次执行：立即执行一次
- 循环执行：按定时或条件循环执行
- 条件分支：根据条件执行不同分支

---

## 注意事项

1. 部分工具需要API密钥或OAuth授权
2. 首次使用需配置工具连接
3. 定时任务依赖系统定时器，确保运行环境稳定
4. 敏感操作（如发送短信）需二次确认
