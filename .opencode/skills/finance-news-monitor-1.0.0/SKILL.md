# Finance News Monitor - 财经新闻与行情监控快报

## 核心功能

### 📰 新闻监控
- **定时快报**：每3小时自动抓取（00:00/03:00/06:00/09:00/12:00/15:00/18:00/21:00）
- **突发新闻**：关键词实时监控（降息、加息、降准、崩盘、熔断、战争、央行行长等）
- **多源聚合**：财联社、同花顺、东方财富、雪球华尔街见闻

### 📈 行情追踪
- **实时行情**：A股、港股、美股、指数、基金、债券
- **大宗商品**：黄金、白银、原油、铜、螺纹钢
- **外汇市场**：美元指数、人民币汇率、数字货币
- **资金流向**：主力资金净流入/流出、北向资金

### 📊 快报生成
- **每日快报**：00点午夜、03点凌晨、06点早间、09点早盘、12点午间、15点收盘、18点晚间、21点夜盘
- **突发快报**：关键词触发即时生成
- **日报汇总**：每日23:50合并生成日报
- **周报汇总**：每周日23:00生成周报

## 技术实现

### 抓取方式
1. **HTTP API**：东方财富财经API（需API Key）
2. **网页抓取**：web_fetch / browser 自动化
3. **数据缓存**：本地JSON文件存储，避免重复请求

### 执行流程
```
1. 检查当前时段 → 获取对应数据源
2. 抓取新闻列表 → 按关键词过滤
3. 获取实时行情 → 格式化数据
4. 生成快报 → 保存到文件
5. 发送通知 → 推送到飞书/微信
```

### 依赖工具
- eastmoney_financial_data：东方财富行情/财务数据
- web_fetch：网页新闻抓取
- browser：浏览器自动化（备用）
- message：消息推送

## 注意事项

1. 部分数据源可能存在延迟（1-5分钟）
2. 行情数据仅供参考，不构成投资建议
3. 抓取频率过高可能触发反爬，请合理设置
4. 突发新闻监控依赖关键词匹配，可能存在遗漏
