# InfoHub Pro - 跨平台信息聚合与结构化导出

## 快速开始

### 1. 添加数据源

告诉我要抓取哪些平台：
- 短视频平台：抖音、B站
- 社交平台：小红书、知乎、公众号
- 文档平台：飞书文档、Notion、网页链接
- 视频平台：YouTube

### 2. 输入抓取指令

使用自然语言描述需求，例如：
- "抓取近7天小红书'跨境电商选品'相关高赞笔记，点赞量≥500"
- "抓取B站AI工具分区近3天播放量≥1万的视频"
- "抓取公众号'AI'相关最新10篇文章"

### 3. 配置提取字段

选择需要提取的信息：
- 视频：标题、UP主、播放量、时长、核心文案、字幕原文、下载链接
- 图文：标题、作者、发布时间、正文核心观点、配图链接、标签
- 文档：目录、关键数据、核心结论、表格

### 4. 设置分类规则

自动打标维度：
- 主题：AI、职场、学习、电商、营销等
- 用途：调研、素材、知识储备、竞品分析
- 优先级：高、中、低

支持自定义标签体系。

### 5. 导出格式

选择输出方式：
- 飞书多维表格
- Excel (.xlsx)
- Markdown文档
- Notion页面
- PDF简报

## 可用命令

### 抓取命令

```
抓取 [平台] [关键词] [时间范围] [热度条件]
```

示例：
- `抓取小红书 跨境电商选品 近7天 点赞≥500`
- `抓取B站 AI工具 近3天 播放量≥10000`
- `抓取公众号 AI 最新10篇`

### 导出命令

```
导出为 [格式]
```

示例：
- `导出为飞书多维表格`
- `导出为Excel`
- `导出为Markdown`

### 查看状态

- `查看数据源` - 列出当前配置的平台
- `查看抓取结果` - 查看最近抓取的数据
- `查看标签体系` - 查看当前分类规则

## 技术实现

### 数据抓取方式

1. **网页链接**：使用 web_fetch 或 browser 自动化抓取
2. **飞书/Notion**：使用 feishu_doc / feishu_wiki 接口
3. **B站/抖音/小红书**：通过 browser 自动化或 API（如有）

### 数据处理流程

1. 抓取原始内容
2. 提取关键字段（标题、作者、时间、内容、热度）
3. 智能分类打标
4. 结构化存储
5. 按需导出

### 依赖工具

- web_fetch：网页内容提取
- browser：浏览器自动化
- feishu_doc：飞书文档操作
- feishu_wiki：飞书知识库操作

---

## 注意事项

1. 部分平台（如抖音、小红书）可能需要登录或存在反爬限制
2. 抓取大量数据时注意请求频率，避免被封
3. 尊重版权，抓取内容仅供个人学习使用
