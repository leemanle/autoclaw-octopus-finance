# DataInsight Lite - 本地数据智能分析与可视化汇报

## 快速开始

### 1. 导入数据

上传本地数据文件：
- Excel (.xlsx, .xls)
- CSV 文件
- 飞书多维表格导出
- Notion 数据库导出
- TXT 文本数据

选择需要分析的工作表和字段。

### 2. 输入分析指令

用自然语言描述分析需求，例如：
- "分析2024年3月-5月的销售数据，按产品类别统计销售额占比"
- "找出环比增长最快的3个产品"
- "计算客单价平均值"
- "分析广告投入与销售额的关联度"

### 3. 自动分析与可视化

Skill自动完成：
- 数据清洗（识别缺失值、重复值、异常数据）
- 分析计算（趋势、占比、排名、相关性）
- 图表生成（自动匹配最佳图表类型）

### 4. 预览与调整

查看分析结果和可视化图表，可：
- 调整图表样式（颜色、字体、图例）
- 添加数据标签
- 补充自定义结论

### 5. 导出报告

选择输出格式：
- Word 文档
- PDF 报告
- Markdown
- 飞书文档

## 可用命令

### 数据导入

```
导入 [文件路径]
分析 [数据文件] [分析需求]
```

示例：
- `导入 2024年Q2销售数据.xlsx`
- `分析 销售数据.xlsx 按地区统计销售额`

### 分析指令

```
趋势分析 [数据]        - 同比/环比趋势
占比分析 [数据]        - 各类别占比
排名分析 [数据]        - TOP排名
相关性分析 [字段1] [字段2] - 关联度分析
异常值分析 [数据]      - 找出异常记录
```

### 导出命令

```
导出报告为 [格式]
导出图表为 [格式]
```

示例：
- `导出报告为PDF`
- `导出图表为PNG`

## 分析模型

### 趋势分析
- 同比增长率
- 环比增长率
- 移动平均
- 预测模型

### 占比分析
- 饼图/环形图
- 堆积柱状图
- 百分比排名

### 排名分析
- TOP N 排名
- 分类排名
- 分数分布

### 相关性分析
- 相关系数计算
- 散点图可视化
- 回归分析

### 异常值分析
- 标准差法（超出均值2/3倍）
- IQR法（四分位距）
- 自定义阈值

## 输出报告结构

自动生成的汇报文档包含：

1. **数据概览**
   - 数据规模（行数、列数）
   - 时间范围
   - 关键指标摘要

2. **核心结论**
   - 3-5条关键发现
   - 用数据支撑的洞察

3. **详细分析**
   - 各维度拆解分析
   - 趋势/占比/排名详情

4. **可视化图表**
   - 智能匹配的图表
   - 可自定义样式

5. **建议方案**
   - 基于数据的行动建议
   - 优先级排序

## 技术实现

### 数据处理流程

1. 导入并解析数据文件
2. 自动数据质量检测
3. 数据清洗（缺失值/重复值/异常值处理）
4. 按需聚合计算
5. 智能图表匹配
6. 报告生成

### 依赖工具

- Python数据分析：pandas, matplotlib, seaborn
- 报告生成：python-docx, fpdf
- 图表导出：matplotlib, plotly

### 支持的图表类型

| 分析需求 | 推荐图表 |
|---------|---------|
| 占比数据 | 饼图、环形图 |
| 趋势数据 | 折线图、柱状图 |
| 对比数据 | 条形图、分组柱状图 |
| 关联数据 | 散点图、热力图 |
| 分布数据 | 直方图、箱线图 |

---

## 注意事项

1. 数据文件需包含表头（第一行为字段名）
2. 支持的数据量：建议不超过10万行
3. 数值列会自动识别，文本列用于分组
4. 日期列会自动解析，支持多种格式
5. 复杂分析可能需要较长时间处理
