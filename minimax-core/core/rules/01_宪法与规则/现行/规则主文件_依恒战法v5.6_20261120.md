一、交易日闸门。任何股票任务开跑第一件事判今日是否 A 股交易日，周末与法定节假日直接输出「今日休市，任务跳过」，不做任何操作，不查数据不写文件。

三、免责尾行。股票类统一「以上为市场数据梳理，不构成投资建议」；社区论坛类统一「以上为社区信息梳理，不构成投资建议」。放在时间戳前一行，两行都不带分隔线。

### 2.1 基准三符号

T = 启动日（首板或首阳当天那根 K 线，不是买入日）
B = 基准价 = T 日收盘价（前复权，全表唯一基准）
E = 入场日（首板排队 E=T、首阳当天买 E=T、一进二 E=T+1、大智慧次日买 E=T+1）

四种入场共用同一个 B。

### 2.2 基准三定律

所有百分比分母永远是 B，不是买入价、不是 T+1 开盘价；所有窗口从 T 起算，不从 E 起算；激活日 A = 窗口内首次收盘涨幅 ≥8% 那一天，只能是 T+1 / T+2 / T+3。

### 2.3 四禁

禁 E 日收盘当基准、禁成交价当基准、禁 T+1 开盘价当基准、禁「买入后再推 N 天」当窗口。成交价只用于记账与仓位，不参与信号判定。

### 2.4 八档判定顺序（不可颠倒）

① → ⑦ → ⑧ → ② → ③ → ⑥ → ④ → ⑤

任一先触发即当日全清 100%，无次日段、无 50/50 分段、无续持状态机。

### 2.5 八档逐条

第①档 三天激活，只判激活不清仓。T+1 到 T+3 收盘涨幅对 B，首次 ≥8% 记激活日 A；三天全 <8% 判未激活，当日不清仓，T+4 起转第⑥档；窗口不完整既不淘汰也不激活，按未激活处理。

第⑦档 新高次日回撤 2%，只判已激活票与第⑥档二波确认后的持仓票。H = 持仓期最高收盘，初值 B，从 T+1 起逐日比较；触发 = 前一交易日收盘创 H + 今日收盘 < H +（H − 今日收盘）/ H > 2% 三条同时满足；正好 2.0% 不触发；今日创新高不卖并更新 H；不判三情形 = 未激活且未二波确认 / 无可比前一日收盘（最早 T+2）/ H 未成立。

第⑧档 二波三波量价背离，只判已激活票与第⑥档二波确认后的持仓票。四条同时满足才触发：一是当日 vol ≥ 本轮首板日 vol×2，第二波用第二波首板量，第三波用第三波首板量，没有涨停的波用该波首阳量；二是上影线 ≥ 当日振幅 50%，上影 = 最高−收盘，振幅 = 最高−最低；三是收盘位于当日振幅下 1/3，即（收盘−最低）/（最高−最低）≤1/3；四是收盘低于开盘且低于前收。四条全中，14:50 到 14:55 尾盘全清 100%。封死涨停不卖；炸板回封不卖；炸板未回封且四条全中，尾盘清。第三波高点低于第二波高点时不等新高，直接按本条判；第三波放量突破第二波高点且收盘站住，按新趋势重新起算本轮首板量。

第②档 均线破位，只对已激活票与第⑥档二波确认后的持仓票。线 L = min(MA5, MA10) × 0.94，连续 2 个交易日收盘 ≤ L，第 2 天尾盘全清 100%；单日破位不卖，不给第 3 天缓冲。

第③档 破 15% 兜底。收盘 ≤ B × 0.85 即全清 100%，所有票都判。

第⑥档 二波反弹，未激活回调版，已激活票不进本档。回撤低点 C = T+1 到 T+10 内，收盘跌破 min(MA10,MA20) 的交易日中收盘最低的那一天，L = C 日收盘价；C 收盘 ≤ min(MA10,MA20)×0.94 只记候选不立即清，C+1、C+2 内收盘收回 0.94 线上方，破位信号作废但 C 仍是回撤低点锚点，8 天弱势反弹照跑；连续两天收不回 0.94 线，第 2 天收盘清。前高 H2 = T 到 C−1 每天代表价的最大值，代表价默认收盘价，当天（最高/收盘−1）≥5% 时改用最高价。中位价 W =（H2+L）/2。C 日算第 0 天，其后第 8 个交易日为截止。第一道门中位价，8 天内必须有一天收盘 ≥ W；一次都没触到 W，第 7 天收盘提前清；触到 W 但收盘始终站不上，第 8 天收盘清。第二道门前高，站上 W 后 8 天内必须有一天同时满足收盘 ≥ H2 且当日 vol ≥ T 日 vol×0.80，才算二波成立，转第⑦⑧档持仓；只站上 W、收盘始终不过 H2，按弱反弹处理，第 8 天收盘清；二波确认只用 H2 本身，0.95×H2 只作预警不作确认。提前清，收盘跌破 L 当天清；第一次触 W 收盘站不上只记一次失败，第二次触 W 仍收盘站不上且中间没有收盘站上 W，当天清；已收盘站上 W 的票连续 2 个交易日收盘跌回 W 下方，第 2 天清。从未出现 C 的未激活票，T 后第 9 个交易日收盘清。

第④档 已并入第②档，同线同条件，保留编号只为判定顺序与触发码可追溯；原「跌破幅度 >5%」与小回调豁免随 5% 阈值一并作废。

第⑤档 21 天创新高检查。每满 21 个交易日查一次；只看最近 21 个交易日窗口，窗口内有一天盘中最高创出买入以来新高，或出现连续 2 个交易日涨幅 ≥5%，就继续持有；两样皆无则到期全清 100%。
