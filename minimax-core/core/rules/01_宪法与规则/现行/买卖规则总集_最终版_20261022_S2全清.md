【现行卖出规则 · 均线版 v5.3（2026-11-05 用户拍板启用）】
判定基准 = 启动日收盘价（前复权）；成交价只用于记账与仓位计算，**不参与任何信号判定**。
每天收盘后判定，优先级从高到低（★ 判定顺序 ①→⑦→②→③→④→⑤；⑥ 只调节④档松紧、不单独卖），七档全部按收盘价判：
1. 3天快速淘汰 / 激活（两线合一 8%）：T+1~T+3（除启动日外）看**收盘**涨幅，相对启动日收盘价
   · 收盘涨幅 ≥8% ⇒ **激活**（★ v5.3.1：激活日 A = 窗口内首次达标日，可 T+1/T+2/T+3）；激活后走第④档；
   · 窗口已满且全 <8% ⇒ 全清 100%；
   · **窗口不完整（交易日历不足 3 天）⇒ 既不淘汰也不激活**，只标注。
⑦. 新高次日回撤2%（第⑦档 · 2026-11-05 新增 · 本版唯一新增档）：只判已激活票；
    H = 持仓期内最高收盘价（起点锚 = 启动日收盘价）；
    触发 = 前一交易日收盘创出 H + 今日收盘 < H + (H−C)/H > 2%（正好 2.0% 不触发）；
    只认收盘价：今日创新高不卖、H 更新；14:50 不满足而收盘满足 → 不追补；
    插在第②档前面当第一道快线，不改任何一档阈值。
2. 均线破位止损：收盘 ≤ min(MA10, MA20)×0.94 ⇒ 全清 100%（MA 含当日收盘；MA10/MA20 都取得到才判，缺数据不放行）。
3. 破15%兜底：收盘 ≤ 基准×0.85 ⇒ 全清 100%（触发码「破15%兜底」）。
4. 移动止盈（以 MA10 为准）：前置 = 已激活；**连续 2 天收盘 ≤ MA10 且跌破 >5%**（收盘 < MA10×0.95）⇒ 全清 100%；
   跌破 ≤5% ⇒ 保留不卖。
5. 21天创新高检查：每满 21 个交易日查一次，窗口 = 最近 21 个交易日；创新高 或 连续 2 日涨 ≥5% ⇒ 继续持有；
   都没有 ⇒ 到期离场，全清 100%。
6. 放量再启动确认：**只作用已激活的票**，且须先回撤到均线；回撤后 8 日内 vol ≥ 启动日 vol×80% 且单日涨 ≥5%
   ⇒ ④档从严；8 日未确认 ⇒ ④档从宽。**本档不单独触发卖出，只调节④档松紧**。

  ⇒ 已有则涨幅透支、**不做**（只标注、不拦卖）；缺数据不拦但标注。
牛股标注：启动日起 15 个交易日内涨幅 ≥24%（基准 = 启动日收盘价）⇒ 只标注，不参与卖出。
执行：尾盘 14:50-15:00 按收盘价判定，触发即**一次性全清 100%**。卖出动作唯一。
