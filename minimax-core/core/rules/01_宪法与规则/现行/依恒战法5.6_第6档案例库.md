## 一、这一档到底在判什么

第⑥档不是买点，是“未激活票回撤之后还有没有第二波”的判断。
回踩 MA10、MA20 只是观察起点，不是买入信号。
真正的卖点由两道门决定。

第一道门是中位价 W。
W =（前高 H2 + 回撤低点 L）/2。
低点后 8 个交易日内，连一天收盘都站不上 W，说明反弹太弱，清。

第二道门是前高 H2。
站上 W 只算活过来，不算二波成立。
还要在 8 天内有一天收盘站上 H2，并且当天量能 ≥ T 日量的 0.80，才算二波成立。
只站上 W、收盘始终不过 H2，是弱反弹，第 8 天照样清。

所以不是“8 天没到前高清”或“8 天没到中位数清”二选一。
是先看 W 保命，再看 H2 确认。
连 W 都不到，死反弹，清。
到 W 不到 H2，弱反弹，清。
到 H2 且量够，二波成立，才转第⑦、第⑧档继续拿。

二波确认只用 H2 本身，不再用 H2×0.95。
0.95 只作预警，不作确认。
这条是 002307 教出来的，后面单独写。

## 二、口径细节

T = 启动日，取本轮最后一个涨停日；本轮没有涨停的，取首阳启动日。
B = T 日收盘价。
C = T+1 到 T+10 内，收盘跌破 min(MA10,MA20) 的交易日中收盘最低的那一天。
L = C 日收盘价。
C 日收盘若 ≤ min(MA10,MA20)×0.94，只记候选，不立即清。
C+1、C+2 两天内收盘收回 0.94 线上方，破位信号作废，但 C 仍是回撤低点锚点，8 天弱势反弹照跑。
连续两天收不回 0.94 线，第 2 天收盘清。
H2 = T 到 C−1 每天代表价的最大值。
代表价默认收盘价；当天（最高/收盘−1）≥5% 时改用最高价，防止长上影把前高压低。
W =（H2+L）/2。
C 日算第 0 天，其后第 8 个交易日为截止。
第一次触 W 收盘站不上，只记一次失败，不立即清。
第二次触 W 仍收盘站不上，且中间没有收盘站上 W，当天清。
已经收盘站上 W 的票，连续 2 个交易日收盘跌回 W 下方，第 2 天清。
收盘跌破 L，当天清。
从未出现 C 的未激活票，T 后第 9 个交易日收盘清。

## 四、H2×0.95 为什么必须废

002307 是最典型的反例。
如果二波确认用 H2×0.95，11/09 收盘 3.59 ≥ 3.543，量 1,673,766 ≥ 2,062,572×0.80=1,650,058，会被判成二波成立。
成立之后，11/13 跌 8.88%，11/17 跌 6.81%，11/19 到 2.76。
按 H2 本身确认，11/09 收盘 3.59 < 3.73，二波不成立，第 8 天 11/12 收盘 3.49 清，避开后面的下跌。
所以 5.6 把 0.95 降级为预警，确认线改成 H2 本身。

## 六、口径边界，不许混用

C 用“收盘跌破均线”，不是“盘中摸到均线”。
东方海洋的 C 是 9/15 收盘 1.97，不是 9/16 最低 1.91。
如果改成盘中最低，东方海洋的 C 会挪到 9/16，L 变 1.91，W 变 2.09，卖点从 9/28 挪到 9/29，原来五例的基线就破了。
002307 的 11/02 是盘中下摸、收盘没破，所以它不算 C，走 T+9 封顶 11/04。
这样反而比等 11/09 摸前高更早离场。
两套口径不能混用，混用就会既想要东方海洋的 9/28，又想要 002307 的 11/02，最后两头都不对。

H2 用代表价，不是纯收盘价。
当天上影 ≥5% 时用最高价，防止长上影把前高人为压低。
北大医药 10/26 上影 5.50%，H2 取 6.14，不取收盘 5.82；W 因此是 5.59，11/10 第二次触线失败才对得上。
盛洋科技 10/21 上影 5.05%，H2 取 10.82，不取收盘 10.30；W 因此是 10.15，10/27 第一次触线才对得上。

## 七、一句话结论

中位价 W 是保命线，前高 H2 是二波确认线。
8 天内连 W 都站不上，清。
站上 W 但收盘始终站不上 H2，也是弱反弹，清。
只有收盘站上 H2 且量能 ≥ T 日 0.80，才算二波成立。
0.95×H2 只作预警，不作确认。
