一、成本基准（统一写死，最终口径 · v5.3.1 加固，本版不动）
==================================================

先把三个符号定义死，后面七档全部只认这三个符号：

  T = 启动日。首板当天、首阳当天那一根K线，就是 T。
      不是买入日，不是次日，不是"开始持仓的那天"。
  B = 基准价 = T 日收盘价（前复权）。
      全表唯一基准，七档共用，不允许任何一档自带基准。
  E = 入场日。真正成交拿到筹码的那一天。
      首板排队 E=T；首阳当天买 E=T；一进二 E=T+1；大智慧信号池次日买 E=T+1。

【基准三定律 · 违反即判错】

  第一定律 · 价格原点
    所有"相对基准"的百分比，分子是判定日收盘，分母永远是 B。
    例：①档 8% 线 = 判定日收盘 ÷ B − 1 ≥ 8%，不是 ÷ 买入价、不是 ÷ T+1 开盘价。
    ③档兜底线 = B × 0.85，不是成交价 × 0.85。

  第二定律 · 时间原点
    所有窗口从 T 起算，不从 E 起算。
    ①档窗口 = T+1、T+2、T+3，一进二在 T+1 才买入，
    但它的①档窗口仍然是 T+1~T+3，不是"买入日再往后推三天"。
    ⑦档 H 的比较从 T 收盘起算，一进二 T+1 的收盘要跟 T 收盘比。

  第三定律 · 激活原点
    激活日 = ①档窗口内第一次收盘涨幅 ≥ 8% 的那一天，记 A。
    A 只能是 T+1、T+2、T+3 三者之一，取第一个达标日。
    不是固定 T+1。T+2 才达标，激活日就是 T+2；后面④⑥⑦档的"已激活"从 A 起算。

【四种入场方式共用同一个 B】

  首板排队买入      E=T     B=T收盘
  首阳当天买入      E=T     B=T收盘
  一进二 T+1 买入    E=T+1   B=T收盘   ← 买入日比基准日晚一天，基准不跟着挪
  大智慧信号池次日买 E=T+1   B=T收盘   ← 同上

  一进二高开 5% 以上买入时，买入价天然高于 B 一大截。
  这个价差是买入成本，不是信号基准，不得拿它去判任何一档。

【四禁 · 出现即判错，必须退回重算】

  禁一把 E 日收盘价当基准（一进二会整体偏移一天）。
  禁二把第一笔成交价当基准（高开买入会整体抬高基准）。
  禁三把 T+1 开盘价当基准（旧版已废口径，禁止复活）。
  禁四把"买入后再往后推N天"当窗口（窗口只从 T 起算）。

【自检 · 每次判定必须打印，可审计】

  输出格式固定为：T=YYYYMMDD，B=数值（前复权），E=YYYYMMDD，入场方式。
  B 必须等于该票 T 日那根K线的收盘价经前复权后的值。
  B 不等于任何成交价；B 与 E 日的价格差不得进入任何判定公式。
  B 取不到 ⇒ 该票全部档位不判（缺数据不放行），禁止用成交价顶替。

模拟盘第一笔买入成交价只用于记账与仓位计算，不参与任何信号判定。

一·B、启动日前置闸（确认是首板/首阳启动日）
==================================================

启动日当天必须确确实实是首板或首阳启动日，前置闸：
  标的近10个交易日内（含启动日）不得出现第二条涨幅超涨停幅度80%的大阳线：

  主板（沪深）涨停10% → 大阳线红线 = 单日涨幅 ≥ 8%
  创业板涨停20%     → 大阳线红线 = 单日涨幅 ≥ 16%
  科创板涨停20%     → 大阳线红线 = 单日涨幅 ≥ 16%
  北交所涨停30%     → 大阳线红线 = 单日涨幅 ≥ 24%

10日内已有第二条达标大阳线的个股，视为涨幅透支，不是首板/首阳启动日，不做。
缺数据（停牌/新股）：不拦但标注。

二、卖出判定优先级（每天收盘后判定，按顺序）
==================================================

判定顺序：① → ⑦ → ② → ③ → ⑥ → ④ → ⑤

  先说清各档管谁，别混：
    ① 判激活，对所有票；
    ⑦ ② ④ 只对已激活票；
    ⑥ 只对未激活票；
    ③ ⑤ 对所有票。

  两套主线彻底隔开：
    激活票走 ⑦ → ② → ④，不会走进⑥档；
    未激活票走 ⑥ → ③，不会碰⑦档。
  所以⑦与⑥、②与⑥之间不存在"谁先卖"的冲突。

  任一档先触发先卖，卖一次即全清100%，各档互不豁免、互不凌驾
  （唯一例外是第⑥档的缓冲期，见⑥档条文）。

【第①档】三天激活判定（v5.4 改动：只判激活，不再清仓）
─────────────────────────
  基准 B = 启动日 T 收盘价（前复权）。
  窗口固定为 T+1、T+2、T+3 三个紧邻交易日（按市场交易日历，停牌复牌那天不算 T+1）。

  逐日判定（三天里每天只看一根收盘）：
    T+1 收盘 ÷ B − 1 ≥ 8%  → 激活，激活日 A = T+1
    T+1 未达 8%，看 T+2：
      T+2 收盘 ÷ B − 1 ≥ 8% → 激活，激活日 A = T+2
    T+2 仍未达 8%，看 T+3：
      T+3 收盘 ÷ B − 1 ≥ 8% → 激活，激活日 A = T+3
    T+1、T+2、T+3 三天全部 < 8% → 判为「未激活票」，
      当日不清仓，从 T+4 起转入第⑥档，按⑥档流程走。

  ★ 这是本版最要紧的一处改动：
    旧口径是「三天不达标，T+3 收盘全清」，把没启动的票直接砍掉。
    新口径是「三天不达标，不清，给它一次回调起二波的机会」。
    为什么改：实测未激活票里有一小撮会在回调到均线后拉出二波，
    旧口径在第三天就把它们全砍了，一只都拿不到。

  激活日 A 的定义：
    A = 窗口内第一次收盘涨幅 ≥ 8% 的那一天，只能是 T+1 / T+2 / T+3 之一。
    A 是④档、⑦档"已激活"的唯一计时起点，全部从 A 起算，不从 T+1 起算。

  一进二特别说明（最容易算错的地方）：
    一进二在 T+1 开盘才买入，E=T+1，但①档窗口仍然是 T+1~T+3。
    不允许把窗口改成"买入日 +1、+2、+3"（那就变成 T+2~T+4，整档错位）。
    它买入那天 T+1 的收盘，就是窗口第一天，当天就可能直接激活。
    换句话说：一进二买入时，①档第一天已经走完了，留给它的是 T+2、T+3 两天。

  大智慧信号池次日买：与一进二完全相同，E=T+1，窗口仍是 T+1~T+3。

  说明：激活线与淘汰线合一，同一把尺子（8%），不存在 5% vs 8% 矛盾。
  窗口不完整（缺 T+1 / 不足 3 个交易日 / 停牌断档）不触发本档，
    既不淘汰也不激活，按未激活票处理，从有数据那天起算第⑥档。

【第⑦档】新高次日回撤2%（2026-11-05 新增，本版不动）
─────────────────────────
  适用范围：
    已激活票（第①档定义：T+1~T+3 收盘涨幅 ≥ 8%）。
    未激活票不判本档，未激活票的回调归第⑥档管。

  H 的定义（v5.3.1 写死起算过程，消灭歧义）：
    H 的初值 = B = T 日收盘价（前复权）。
      H 从 T 收盘开始，不是从买入价开始，不是从 T+1 开盘开始。
    从 T+1 起逐日比较收盘：
      某日收盘 > 当前 H  → 该日收盘成为新 H（这天叫新高日）
      某日收盘 ≤ 当前 H  → H 不变
    T 之前的高点一律不算；T 当天的收盘本身就是第一个 H。
    一进二虽然 E=T+1，但 H 的初值仍然是 T 收盘；
      T+1 的收盘要跟 T 收盘比，高于 T 收盘才算新高日。

  H 与买入成本的关系（v5.3.1 写明的已知边界，不改 2% 阈值）：
    H 与买入价无关。一进二高开 5% 买入、成交价可能已经高于 B 一大截，
    H 仍然从 B 起算。后果是：
      股价要从买入价回落到 B×0.98 才触发⑦档，
      不是从买入价回落 2% 就触发。
    也就是说高开买入的票，⑦档天然更宽，卖点比按买入价算更晚、更低。
    这是基准错位，本版只写明，不改阈值（2026-11-05 已拍板 2% 不放宽）。

  触发条件（两个必须同时满足）：
    ① 前一交易日收盘创出 H（即前一日是「新高日」）
    ② 今日收盘 < H，且今日收盘相对 H 回撤 > 2%
    公式：(H − C) / H > 2%   且   C < H

  只认收盘价：
    盘中冲高、盘中回撤都不算；今天收盘创新高就继续持有，H 更新为今天收盘，重新起算。

  边界：
    H = 10.00
    C = 9.75（回撤 2.5%）  → 触发
    C = 9.80（正好 2.0%）  → 不触发（必须超过 2%）
    C = 9.79（回撤 2.1%）  → 触发
    C = 10.05（创新高）    → 不卖，H 更新为 10.05

  执行（依恒战法全清，无分段）：
    14:40 用现价近似当日收盘价判定，满足即 14:40–14:55 挂单全清 100%
    14:40 不满足而收盘满足 → 不追补，次日按新 H 与新收盘继续判
    不满足 → 继续持有，H 不变

  不判的三种情形：
    一、未激活：T+1~T+3 三天收盘都没到 B×1.08，A 不存在，⑦档整档不判。
    二、没有可比的前一日收盘：判定日最早是 T+2。
    三、H 未成立：从 T 到判定日，没有任何一天的收盘高于 B，⑦档不判。

  为什么用 2%：
    2026-08~09、415 笔同口径回测（A=v5.2 原六档 / B=本档单用 / C=先本档、A 兜底）
    A 总收益 +6.15%、中位 +0.92%、胜率 54.0%、平均持有 11.1 日
    B 总收益 +9.57%、中位 +7.37%、胜率 70.8%、平均持有 10.4 日
    C 总收益 +12.40%、中位 +7.82%、胜率 74.9%、平均持有 5.2 日
    阈值扫描（C 方案）：2%→12.40% / 3%→11.87% / 4%→11.35% / 5%→10.71% / 6%→10.02% / 8%→9.38%
    → 越紧越好，2% 最优，2026-11-05 用户拍板「就按 2%，不放宽」。

  已知缺口（必须并排原档使用，不可单用）：
    415 笔中 71 笔（约 17%）全程从未触发，这 71 笔平均持有期最高只涨 10.0%、
    平均收益 −20.29%；靠第②③④⑤档兜底。
    本档会卖早部分大牛（001326 最高 +113%，A 81.2%/43日 vs B 15.7%/8日）。

【第②档】均线破位止损（v5.4 收窄：只对已激活票）
─────────────────────────
  触发条件：
    收盘价 ≤ min(MA10, MA20) × 0.94
  操作：全清100%

  适用范围（v5.4 改动）：
    只对已激活票生效，当日收盘即全清，不给缓冲。
    未激活票跌破同一条线，不执行本档，交给第⑥档（缓冲 + 二波窗口）。
    为什么这样分：已激活的票涨过一波了，破位就是走坏，不指望它再起二波；
    没激活的票还没涨过，才值得给它一次回调反弹的机会。

【第③档】破15%兜底（v5.2 原样，本版不动）
─────────────────────────
  触发条件：
    收盘价 ≤ 基准（启动日收盘价） × 0.85
  操作：全清100%

  适用范围：所有票，已激活、未激活都判。
    这一档排在⑥档之前，意思是：未激活票在等二波的过程中，
    一旦跌穿 B×0.85，不等二波窗口走完，当场清。
    不给"再等等看"的余地。

【第④档】移动止盈（以MA10为准）（v5.2 原样，本版不动）
─────────────────────────
  前置条件：
    已激活（第①档：3天窗口收盘涨幅 ≥ 8%，
            激活日 A = 窗口内首次达标日，可为 T+1 / T+2 / T+3）

  触发条件：
    连续2天收盘 ≤ MA10，且跌破幅度 > 5%

  跌破幅度的算法（本版写死，消除歧义）：
    跌破幅度 = (MA10 − 当日收盘) ÷ MA10
    必须 > 5%，正好 5% 不触发。

  操作：全清100%

  例外：
    跌破幅度 ≤ 5%的小回调可以保留，不卖出。

【第⑤档】21天创新高检查（v5.2 原样，本版不动）
─────────────────────────
  触发条件：
    每满21个交易日检查一次，窗口内没创新高也没连续大阳线
  操作：离场全清

  说明：自持仓第一根K线算第 1 天（首板 E=T 时即 T，一进二 E=T+1 时即 T+1），
        窗口 = 最近 21 个交易日；
        ★ 这里的"第 1 天"只是**持仓计数原点**，不是价格基准；
          价格基准永远是 T 日收盘价 B，两者不要混。
  创新高 = 窗口内有一天盘中最高价创出自持仓第一根以来新高（含除权调整）；
  连续大阳线 = 窗口内连续 2 个交易日涨幅 ≥ 5%（持仓第一根的大涨是入场本身，不算）。

【第⑥档】二波反弹确认（未激活回调版 · 2026-11-09 定稿）
─────────────────────────
用户原话（原样保留，不得改写）：
  「收盘价跌破 ma10 或 ma20 乘以 0.94，以最低那条均线为准，你不要乱给我改，
    允许只破 2 天，如果第三天收不回来就止损，第三天开始之后的收盘价必须都要收回，
    ma10 或 ma20 乘以 0.94。另一个，也就是，从第 3 天站上 ma10 或 ma20 乘以 0.94，
    重新数 5 个交易日。最多等 5 天，必须到前高的 95%，达标了就继续持有。」

这一档管的是什么（v5.4 核心改动）：
  管「三天没激活、回调到均线附近、又拉起来」的票。
  不是管激活以后的回调。
  旧版管的是激活后回调，那一类票在实盘里早被第⑦档的回撤 2% 卖掉，
  根本走不到均线，⑥档等于空转。本版把它翻过来，管没人管的那一类。

适用对象：
  第①档 T+1~T+3 三天收盘都没到 B×1.08 的票，记「未激活票」。
  已激活票不进本档，走②④⑦。

破位日 R：
  从 T+4 起逐日看收盘，第一次 收盘 ≤ min(MA10, MA20) × 0.94 的那一天，记 R。
  T+1~T+3 三天不记破位，那三天只判激活，不许两头都占。
  只认收盘价，盘中破不算。
  两条均线取较低的那条乘 0.94，也就是哪个更低用哪个。
  取不到 MA20（新股不足 20 根）：只用 MA10×0.94。

前高 H2：
  取 T 到 R−1 这一段里的最高收盘价（前复权），记 H2。
  含 T 当天收盘。T 之前的最高价一律不算。
  二波要回去的目标位就是这个前高。

缓冲：
  R 当天不卖。
  R+1、R+2 两天只观察，不判成立也不判失败。
  缓冲期内第③档先触发，照③档执行，不因缓冲豁免
    （未激活票不适用②档，所以缓冲期内只有③档会先砍）。

窗口与判据：
  R+3 到 R+7，五个交易日，必须有一天同时满足下面两条：
    (a) 反弹到前高附近：当日收盘 ≥ H2 × 0.95
    (b) 放量到启动日八成：当日成交量 ≥ T 日成交量 × 0.80
