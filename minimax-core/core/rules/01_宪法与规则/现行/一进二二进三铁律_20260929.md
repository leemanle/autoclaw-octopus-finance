## 二、统一框架（两个系统共用，只有参数不同）

### 入口定义
一进二池 = 昨日真首板
        昨日封板 且 前一交易日未封板
二进三池 = 昨日二板
        昨日封板 且 前一交易日也封板 且 再前一日未封板

### 统一五维（两系统都跑五维，不许只跑开盘档）
维度一 开盘档
  今日开盘涨幅 = open_price / prev_price - 1
  分档 低开<0 / 平开0-2 / 2-4% / 4-7% / 高开7%+
  分档函数必须自检，负开盘落 低开<0，不得错判进 平开0-2
  这是历史样本最单调的维度，两系统主判据

维度二 昨日资金面
  Tushare moneyflow 取前一日
  大单净额 = buy_lg + buy_elg - sell_lg - sell_elg
  全单净额 = net_mf_amount
  moneyflow 金额单位是万元，circ_mv 是亿元
  占比% = 净额(万元) / (circ_mv(亿元) * 1e4) * 100
  这一条曾经算错 100 倍，已修正

## 四、涨停原因数据积累制度

同花顺涨停池不接历史日期，传 date 与不传 date 返回完全一样。
所以历史涨停原因只有一个办法：每天跑，每天落盘。

落盘路径 C:\Users\Administrator\Desktop\选股系统备份\涨停池原因_YYYY-MM-DD.json
结构 {date, source, total, items[]}
每只含 ticker / name / limit_up_reason
          / continue_day_text / limit_up_time / seal_money

15:10 收盘复盘档位必须每天执行这一步。
这是整个系统唯一能积累涨停原因历史文本的路径。
