二、卖出侧（本框不做模拟盘，但结论必须标注 · 两段式）
· 唯一通道 = 两段式：触发信号一律尾盘（14:50-15:00）确认；
  尾盘先卖 50%（整手向下取整，至少 1 手），剩余 50% 次日开盘 09:25-09:35 处理。
· 移动止盈（主通道）：激活 = 买入后盘中最高 ≥ 成本×1.05，峰值收盘只升不降，
  尾盘收盘 ≤ 峰值×0.98 触发；
  次日开盘价 ≤ 触发日收盘价 → 全卖剩余 50%；
  次日开盘价 > 触发日收盘价（高开走强）→ 剩余 50% 继续持有，重回移动止盈跟踪
· 破-15%兜底：尾盘收盘 ≤ 成本×0.85 → 尾盘卖 50%，
  次日开盘无条件清剩余 50%（不看高开）
· 40日强平：满 40 个交易日 → 尾盘卖 50%，次日开盘无条件清剩余 50%（不看高开）
· 连亏 3 笔 → 降半仓或停手 3 个交易日
· 执行顺序：破-15% → 止盈回撤2% → 强平40日。★不设固定%止损。
· ★不设固定%止损（244笔实测破5%止损最毒；纯移动止盈均值+2.49%、胜率56.6%，
  加破5%止损后均值+0.75%、胜率43.9%）
· 铁律：尾盘后才定形态（盘中一律「进行中·尾盘后才定案」）；
  判定用收盘价；分两段卖、无盘中补卖、超窗拒绝执行、不得折中价成交
