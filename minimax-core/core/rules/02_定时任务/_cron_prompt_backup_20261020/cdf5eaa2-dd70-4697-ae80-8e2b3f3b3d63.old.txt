## 唯一现行规则（灵魂宪法第 X+10 条，2026-10-20 最终版定稿）
【卖出】唯一通道，**两段式执行**：
触发信号一律在尾盘（14:50-15:00）确认；确认后先卖一半，剩余一半次日开盘看情况。
第一段（触发日尾盘 14:50-15:00）：任一卖出信号尾盘确认 → 卖出该持仓 50%
（按整手向下取整，至少 1 手）。
第二段（次日开盘 09:25-09:35）：剩余 50% 看次日开盘——
· 移动止盈：开盘价 ≤ 触发日收盘价 → 开盘价全卖剩余 50%；
  开盘价 > 触发日收盘价 → 高开走强，剩余 50% 继续持有，重回移动止盈跟踪
· 破-15%兜底 / 40日强平：次日开盘无条件卖出剩余 50%，不看高开
信号判定（用尾盘收盘价）：破-15%兜底 收盘≤成本×0.85 → 移动止盈回撤2%
（激活=买入后盘中最高≥成本×1.05，且收盘≤峰值收盘×0.98）→ 40日强平 持有满40个交易日
执行顺序：破-15% → 止盈回撤2% → 强平40日。★不设固定%止损。
【成本基准】第一笔买入成交价，禁止摊薄均价（总集 §1.4）
【选股】首板硬定义：当日封死涨停(主板10%/双创20%)+连板数0+5日内无涨停+非ST
  ★废除涨幅过滤(5/10/20日上限)、废除涨停稀疏度过滤、废除30/40/60闸
  排序加分：距上一涨停5-10天；集群铁律：高标带队+同日≥2只同事件，孤板弃
  盘口：首封09:25-09:40、炸板≤2、流通15-70亿、换手>30%剔除
  情绪：高潮日(涨停>80或首板>70且炸板率<15%)不追首板；分歧日才是主战场
【铁律】一、尾盘后才定形态（盘中一律「进行中·尾盘后才定案」）
        二、卖出分两段：尾盘卖50% + 次日开盘处理剩余，没有其他盘中补卖路径
        三、判定用收盘价，动作在尾盘与次日开盘两处执行，不得折中价成交
【持仓规定】最多 4 只，每只平均仓位 25%
【作废】首板v3全部（买前10日涨10~30%、D1/D2破成本卖、第4日收盘清仓、+30%止盈单）；
        第X+7条第二款（止盈15/25/30、止损5/8/10、35%被动减仓）；
        「收盘全卖」「次日开盘全卖」旧单段式口径（已被两段式取代）；全部选股红线。
        作废脚本 sell_v3 / pick_v3 / _v3_diag / redline_new / redline_jy 已置空。
