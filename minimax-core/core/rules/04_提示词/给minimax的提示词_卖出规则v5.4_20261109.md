二、成本基准（统一写死，禁止用成交价判信号）
==================================================

三个符号先定义死：

  T = 启动日（首板/首阳当天那根K线，不是买入日）
  B = 基准价 = T 日收盘价（前复权，全表唯一基准）
  E = 入场日（首板排队 E=T；首阳当天买 E=T；一进二 E=T+1；大智慧次日买 E=T+1）

信号判定统一用固定基准，可回测可复现：

  统一基准 = B = 启动日收盘价（前复权）

无论首板排队、首阳入场、还是一进二（T+1买入），全部统一用同一个 B。

★ 基准三定律（违反即判错）：
  ① 价格原点：所有百分比的分母永远是 B，不是买入价、不是 T+1 开盘价。
     ①档 8% 线 = 判定日收盘 ÷ B − 1；③档兜底 = B × 0.85。
  ② 时间原点：所有窗口从 T 起算，不从 E 起算。
     一进二 E=T+1 买入，①档窗口仍是 T+1~T+3，不是「买入日再往后推三天」。
  ③ 激活原点：激活日 A = 窗口内首次收盘涨幅 ≥8% 的那一天，
     只能是 T+1/T+2/T+3 之一，不是固定 T+1。

★ 四禁：
  禁把 E 日收盘当基准
  禁把成交价当基准
  禁把 T+1 开盘价当基准
  禁把「买入后再往后推N天」当窗口

★ 一进二特别提醒：买入价高于 B 是成本，不是基准。
  高开 10% 买入，股价要跌 9.3% 才回到 B，跌 11.1% 才到 B×0.98；
  这期间⑦档天然更宽、卖点更晚更低，属已知基准错位，本版只写明、不改 2%。

模拟盘第一笔买入成交价只用于记账与仓位计算，不参与任何信号判定。

★ 自检：每次输出必须打印一行
  T=YYYYMMDD，B=数值（前复权），E=YYYYMMDD，入场方式
  B 必须等于该票 T 日那根K线收盘价；B 不等于任何成交价；
  B 取不到则该票全部档位不判，禁止用成交价顶替。

四、卖出判定优先级（每天收盘后判定；顺序 ① → ⑦ → ② → ③ → ⑥ → ④ → ⑤，⑥ 未回前高直接清仓）
==================================================

【第①档】三天激活判定（v5.4：只判激活，不再清仓）
  基准 = B = 启动日收盘价（前复权），启动日记 T
  3天 = 除启动日外，从第二天（T+1）开始算，往后推3个交易日（T+1、T+2、T+3）
  判定 = 看 T+1~T+3 的收盘涨幅（相对 B）
  逐日判：
    T+1 收盘涨幅 ≥ 8% → 激活，激活日 A = T+1
    T+1 未达，看 T+2；T+2 达标 → A = T+2
    T+1、T+2 未达，看 T+3；T+3 达标 → A = T+3
    三天全 < 8%     → 判为「未激活票」，当日不清仓，从 T+4 起转第⑥档
  ★ 激活日 A = 窗口内首次达标那一天，不是固定 T+1。
    旧文「激活第一天 = T+1」是错的：T+2 才达标则 A=T+2，④⑦档一律从 A 起算。
  激活线与淘汰线合一，同一把尺子（8%），不存在 5% vs 8% 矛盾
  窗口不完整（缺T+1 / 不足3个交易日）不触发本档（既不淘汰也不激活，按未激活处理）
  ★ v5.4 起本档不产生任何卖出结论
  ★ 一进二特别说明：E=T+1 买入，但窗口仍是 T+1~T+3。
    买入那天窗口第一天已走完，只留给它 T+2、T+3 两天。

【第⑦档】新高次日回撤2%（2026-11-05 新增 · 本版唯一新增档）
  适用范围：只判已激活票（第①档定义：T+1~T+3 首次收盘涨幅 ≥ 8%，A=首次达标日）；
            未激活票不判本档，走第⑥档
  H 的定义：H = 持仓期最高收盘价（前复权）
    ★ 初值就是 B = 启动日收盘价；T 当天收盘本身就是第一个 H
    ★ 从 T+1 起逐日比较收盘：某日收盘高于当前 H → 该日收盘成为新 H
    ★ T 之前的高点不算
    ★ H 与买入价无关（一进二高开买入时，要从买入价回落到 B×0.98 才触发）
    前一日收盘创出持仓期新高，则该收盘价即 H
  触发条件（两个必须同时满足）：
    ① 前一交易日收盘创出 H（前一日是「新高日」）
    ② 今日收盘 < H，且今日收盘相对 H 回撤 > 2%
    公式：(H − C) / H > 2%   且   C < H
  只认收盘价：盘中冲高、盘中回撤都不算；今天收盘创新高就继续持有，H 更新为今天收盘，重新起算
  边界：H = 10.00     C = 9.75（2.5%）→ 触发
                      C = 9.80（正好 2.0%）→ 不触发（必须超过 2%）
                      C = 9.79（2.1%）→ 触发
                      C = 10.05（创新高）→ 不卖，H 更新为 10.05
  执行（依恒战法全清，无分段）：14:40 用现价近似当日收盘价判定，满足即 14:40–14:55 挂单全清 100%
        14:40 不满足而收盘满足 → 不追补，次日按新 H 与新收盘继续判
  不判的三种情形（v5.3.1 按 T 口径重写）：
    ① 未激活（T+1~T+3 三天都没到 B×1.08）
    ② 没有可比的前一日收盘 —— 判定日最早 T+2
       （T+1 只有一根收盘，只能定 H 不能判回撤）
    ③ H 未成立 —— 从 T 到判定日，没有任何一天收盘高于 B
  ★ 一进二在这三情形下的实际表现：高开买入时 B 在下方很远，
    H 常常迟迟不成立，⑦档基本失效，只能靠①档与②档兜底。
  与现有档位关系：平行叠加，不改任何一档阈值；插在第④档（MA10）前面当第一道快线
  回测（2026-08~09、415 笔，同口径）：A=v5.2 +6.15%；B=本档单用 +9.57%；C=先本档、A 兜底 +12.40%
  已知缺口：17% 样本全程未触发（这批均值 −20.29%），靠第②③④⑤档兜底，不可单用

【第②档】均线破位止损（v5.4 收窄：只对已激活票）
  收盘价 ≤ min(MA10, MA20) × 0.94 → 全清100%

  ★ 未激活票跌破同一条线不执行本档，交第⑥档走缓冲与二波窗口，不当日清仓

【第③档】破15%兜底

【第④档】移动止盈（以MA10为准）

【第⑤档】21天创新高检查
  每满21个交易日检查一次（第21、42、63天……）
  每次只看最近21个交易日窗口：
    ① 创新高 = 窗口内有一天盘中最高价创出「自买入日以来」的新高
    ② 连续大阳线 = 窗口内出现连续2个交易日涨幅 ≥ 5%
  两样都没有 → 到期离场全清100%
  只要有一样 → 继续持有不卖

【第⑥档】二波反弹确认·未激活回调版（v5.4 整段重写 · 2026-11-09 定稿）

    必须在 5 天内反弹到激活位附近，并放量达到启动日 80% 的量能之上，如果未达到，及时止损。
  管什么：没到激活线就往下砸、回调到均线附近又开始起第二波的个股。
    ★ 口径已翻转：不是「激活后回调」，是「未激活回调」。
    已激活票不进本档，走②④⑦三条主线，两条主线彻底隔开。
  破位日 R：从 T+4 起，收盘首次 ≤ min(MA10,MA20)×0.94 的那一天，只认收盘
    T+1~T+3 只判激活、不记破位（避免与三天窗口重叠，两头都占）
  前高 H2：T 到 R−1 这一段里的最高收盘（含 T 当天），T 之前不算
  缓冲：R 当天不卖，R+1、R+2 只观察不判；③破15%兜底照常执行

==================================================
十、执行自检清单（每笔卖出前核对）
==================================================

1. 基准用的是 B = 启动日收盘价（前复权），不是成交价、不是次日开盘价、不是入场日收盘价
2. 3天窗口 = T+1~T+3，不含启动日当天，看收盘涨幅；窗口从 T 起算，不从买入日起算；v5.4 起三天没到 8% 只判未激活，不清仓
3. 激活 = 3天窗口**首次**收盘涨幅 ≥ 8%，激活日 A = 首次达标那一天（可 T+1/T+2/T+3），不是固定 T+1
4. 牛股判定用15日窗口、基准启动日收盘、前复权最高价
5. 均线破位用 min(MA10,MA20)×0.94，只对已激活票当日清；未激活票交⑥档
6. 移动止盈 = 连续2天收盘≤MA10 且跌破>5%，小回调(≤5%)保留，只对已激活票
7. 第⑥档只对「未激活、回调到均线附近起二波」的票生效，已激活票不进本档
8. 第⑦档 = 前一交易日收盘创出 H + 今日收盘 < H + (H−C)/H > 2%（正好 2.0% 不触发），只认收盘价，今日创新高不卖、H 更新；H 初值就是 B，从 T+1 起逐日比较，T 之前高点不算，H 与买入价无关；不判三情形 = 未激活 / 无前一日收盘可比（最早 T+2）/ H 未成立；14:40 不满足而收盘满足不追补
8B. 每次输出必带基准自检行：T=YYYYMMDD，B=数值（前复权），E=YYYYMMDD，入场方式
9. 14:40 判定（14:40-14:55 内挂单），触发即一次全清100%
10. 缺数据不判，标注原因，不猜不编
11. 输出带6位代码，两盘各自独立执行

以上为模拟盘自动化执行规则，不构成投资建议。
