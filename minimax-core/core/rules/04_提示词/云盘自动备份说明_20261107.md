# 云盘自动备份配置说明（2026-11-07 拍板）

执行要求：
1. 从2026年11月10日（周一）开始，本机所有定时任务、所有聊天窗口产出的文档，每日收盘后（15:30后）自动增量同步到豆包云盘。
2. 云盘目标位置：豆包云盘根目录下新建「选股系统定时任务自动备份」文件夹。
3. 本地同步路径覆盖：C:\Users\Administrator\Desktop\选股系统备份\ 目录下所有产出文件，含每日报告、台账、规则文档、脚本产物。
4. 同步方式：增量推送，仅上传新增/修改的文件，历史版本保留，不删除远端旧文件。
5. 冲突策略：本地版本为准，同名文件覆盖云端旧版本，不做双向拉取。
6. 无需用户手动触发，每日收盘后自动执行，同步完成记录当日日志。
