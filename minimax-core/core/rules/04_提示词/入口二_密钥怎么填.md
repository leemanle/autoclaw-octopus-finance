# 入口二 · 密钥怎么填

本包不含任何明文密钥。6 把密钥分别对应 3 个平台，
你在各平台后台点「重置」拿到新值，再填进本机环境变量。

## 三个平台、三把 key

① tushare（个人中心 → 接口 token）
　环境变量：TUSHARE_TOKEN

② 同花顺 fuyao（fuyao 域名下的 key）
　环境变量：THS_KEY

③ 妙想 问财 skill-hub
　环境变量：IWENCAI_SKILLHUB_KEY

## 另三把（插件侧，与模拟盘账户无关）

　MX_APIKEY / MX_KEY_A / IFIND_JWT / HITHINK_API_KEY /
　IWENCAI_API_KEY
　见「插件KEY与账号清单_明文.md」，同样只留占位符。

## 填写方式

· 写进系统环境变量（不要写进聊天框、不要提交进包）
· 校验：python -X utf8 -c "import os; print(bool(os.environ.get('THS_KEY')))"
· 读密钥一律走 mx_cred.expect() / scheduler.env_reader.read_*()，
　不要在代码里直接读 os.environ。

## 轮换后要重打的三处

· 引擎侧 config/rules.json 与 pos_guard_rules.json 若引用了密钥路径
· 交接包（A 包）附件C 的引擎副本
· 股票克隆包本体
