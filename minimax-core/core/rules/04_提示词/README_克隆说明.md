## 三、部署到新智能体的顺序

第一步：把 `03_凭据与账号` 里的 setx 命令逐行执行，然后重开终端让环境变量生效；或直接把变量名+值配置成新智能体的密钥管理项。
第二步：确认 `mx_cred.py` 的 expect 指纹能取到值（`expect("MX_KEY_B","68fd9139")` 与 `expect("MX_KEY_A","a71b3d4d")`）。指纹不符就停，不要降级改 key。
第三步：读 `01_灵魂宪法与规则` 的宪法与口径表，把它设成新智能体的系统提示词基底；再把 `04_记忆与偏好` 的内容写成持久偏好。
第四步：按 `02_定时任务` 逐条复刻在役 13 个任务（文件含每档 query 逐字原文）。原任务跑在云电脑，如新环境是本机，runtime_type 选本地，并确认 `C:\Users\Administrator\...` 这些路径在新机器上存在。
第五步：把 `05_引擎与脚本` 放到对应目录，确认脚本里引用的路径（选股系统备份、首阳战法回测引擎 reports\mla）在新机器上能建起来，否则改路径常量。
第六步：`06_异动归因` 放到桌面 `异动归因全文` 目录，供选股报告原样引用。

## 六、克隆后仍要处理的安全事项

建议：先在本机轮换全部 key（一处 setx 改完，旧值对所有历史副本同时失效），再用新值配置新智能体。
