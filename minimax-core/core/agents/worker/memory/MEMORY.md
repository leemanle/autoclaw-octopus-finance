# B站足球官方素材侦查：可复用的账号与发布规律

> 首次沉淀 2026-11-01（worker）。用于足球短视频项目的「素材侦查」环节。

## 1. 判据（不可放宽）
- 官方认证 = `card` 接口 `data.card.official_verify.type == 1`。
- `type` 为 -1 / 0 一律搬运号；简介含「感谢审核」也是搬运号，一律禁用。
- 官方 ≠ 可用：媒体号（咪咕/直播吧/懂球帝/央视网/天下足球）虽是 type=1，
  但只发图文解说或十几秒短片，不含 65%-80% 比赛画面 ⇒ 不可用于成片。

- **曼联**：标题「比赛集锦 | 英超联赛 | …」，赛后次日 10:00 准时，约 2 分钟。
- **曼城**：标题「【比赛集锦】…」，赛后次日 12:00，约 2 分钟（比曼联晚 2 小时）。
- **马竞**：标题「【全场集锦】X-N Y」，赛后**当晚**约 23:00，约 3 分钟（最早）。
- **利物浦**：标题「比赛集锦 | X-N Y」，赛后次日约 11:00，约 2 分钟。
- **英超联赛官方号**：只发 12-23 秒片段 + 每轮 3-5 分钟「第N轮进球合集」，**不发全场集锦**。

- 皇马号有每轮赛后集锦体例（如 10-26「姆巴佩双响！皇马2-1力克巴萨」3:01）。

## 5. 技术坑（2026-11-01 实测）
- **`_get` 里必须写 `global COOKIE`**：漏写会让 `COOKIE` 变局部变量 →
  `UnboundLocalError`，所有 card/search 返回空（表现为 ov_type=None，像被限流，其实是代码 bug）。
  症状相同，别误判成风控。
- **card 接口 412 退避**：3/6/11/18/28/40 秒；大号尤其容易 -352。
  连续调用几十次后会持续 412，此时应停手而不是继续加压。
- **动态流接口 `x/polymer/web-dynamic/v1/feed/space`**：对曼城/英超联赛号返回 **-352**，取不到；
  改用 `x/space/wbi/arc/search`（`_bili_wbi.py`）才拿得到投稿列表。
- **wbi 路 A 的正确用法**：`full_fingerprint(mid)` → `nav_keys()` → `arcs(mid, ps=50, pn=1..2)`；
  每次失败会自动换指纹重试，412 时能成功，但要等（单页可能 1-2 分钟）。
- **搜索接口 `author` 是字符串**，mid 在顶层 `v.get("mid")`；不能从 author 取 mid。
- 搜「阿拉维斯」会大量命中阿斯顿维拉系账号（子串碰撞），搜「莱万特」会命中同名手游。
- 下载大文件别用 `bili_slice._get`（整包进内存），用 `bili_slice.download`（走 ffmpeg 拉流）。

## 6. 抽帧核验做法
- `ffmpeg -vf fps=1/2,scale=480:-1` 抽帧 → concat + tile 拼接触表 → 视觉模型看记分牌。
- 记分牌在**左上角**，裁 `crop=230:70:0:0` 再放大 3 倍拼图，一眼看清队徽缩写和比分。
  比看整张接触表快得多，也更可靠。
- 官方 LALIGA/英超转播的左上角记分牌带队徽+三字母缩写（LEV/ATM、BAR/ALA、CHI/MUN）。
