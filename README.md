# 智能选股系统

## 系统功能

基于你的首板选股公式实现的自动化选股系统：

1. **板块筛选** - 从19个热门板块中选出股票
2. **个股分析** - 板块内涨幅前10的个股
3. **首板识别** - 根据你的公式判断首板
4. **基本面分析** - 利好新闻、概念题材
5. **智能评分** - 综合打分排序
6. **模拟交易** - 自动跟踪（待实现）

## 选股公式

```
首板1:冲>=0.08 AND 过去3天涨幅<=0.085 AND 实体>=0.028 AND 涨幅2>=0.035
首板2:冲>=0.08 AND 涨幅2>=0.09 AND 过去3天涨幅<=0.087
首板:首板1 OR 首板2
```

## 快速开始

### 安装依赖

```powershell
pip install requests
```

### 运行选股

```powershell
python -X utf8 main_scheduler.py
```

或使用简化脚本：

```powershell
python -X utf8 run_selection.py
```

## 配置参数

编辑 `trading_config.py` 调整参数：

```python
# 选股参数
'MIN_SECTOR_CHANGE': 0.01,  # 板块涨幅阈值
'TOP_STOCKS_IN_SECTOR': 10,  # 板块内取前N只
'TOP_SECTORS': 3,  # 分析前N个板块

# 首板参数（根据你的公式）
'MIN_CHONG': 0.06,  # 最小冲高幅度
'MAX_HISTORY_CHANGE_1': 0.09,  # 历史涨幅阈值
'MIN_ENTITY': 0.02,  # 最小实体
'MIN_CHANGE2_1': 0.03,  # 最小涨幅2
'MAX_HISTORY_CHANGE_2': 0.092,
'MIN_CHANGE2_2': 0.08,
```
