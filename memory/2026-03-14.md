## 股票交易策略（核心 - 已记住！）

### 选股流程（每天必执行）
1. **同花顺热门板块排行** → 涨幅>1%的板块
2. **领涨股取前十** → 板块内涨幅前10
3. **首板筛选** → 符合"首板=1"公式
4. **深度分析** → 基本面、行业龙头、市场反馈
5. **最终筛选** → 不超过5只，加自选

### 首板公式
```
首板1:=冲>=0.08 AND EVERY(REF(涨幅2,1)<=0.085,3) AND 实体>=0.028 AND 涨幅2>=0.035
首板2:=冲>=0.08 AND 涨幅2>=0.09 AND EVERY(REF(涨幅2,1)<=0.087,3)
首板3:=首板1 OR 首板2
首板:=首板3 AND EVERY(REF(首板3=0,1),2)
```

### 关键指标
- 涨幅2: (C-REF(C,1))/REF(C,1)  // 相对昨日涨幅
- 冲: (H-REF(C,1))/REF(C,1)    // 冲高幅度
- 实体: (MAX(C,O)-MIN(C,O))/MIN(C,O)
